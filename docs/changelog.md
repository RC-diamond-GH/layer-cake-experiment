# 更新日志

## 1 2026-11-09：Layer Cake MVP

### 1.1 交付内容

- 新建 Rust 工程，按上下文、模型、工具、记录、ReAct、实验控制、事件、环境、响应式执行、报告与回放划分模块。
- 提供脚本模型与 OpenAI-compatible Chat Completions 适配器、内存读写工具、有界 ReAct、不可变快照、因果调用记录和原子本地文件存储。
- 提供注册实验 CLI、交互控制、用户与环境输入、记录查询、静态 HTML 和运行比较。
- 实现熔炉轮询与响应式机制、版本化资源、保留事件、订阅、接收队列、去重和取消；计时器复用同一事件订阅接口。
- 提供严格原实验回放：保存结果替代模型与工具副作用，按原边界重施输入，按调用位置重施在途停止，首个请求分歧立即定位。
- 新增 Lean 投递闸门证明和固定源文件哈希的 Rust／Lean 审阅，保留原自动机与 Workflow／ReAct 示例。
- 整理 README、正式文档索引、使用指南、架构及扩展复用说明；保留 `materials/` 需求材料。

### 1.3 交互与 HTML 验证

## 2 2026-11-09：模型环境配置与 HTTP 诊断

- `run` 命令加载本地 `.env`，已有进程环境优先；OpenAI 示例使用 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 与 `OPENAI_MODEL`。显式模型配置优先于对应环境值。
- 基础 URL 保留路径前缀并追加 `/chat/completions`，解析后的地址与模型名称保存到运行配置，回放继续使用保存值。
- HTTP 失败先按状态处理，再读取提供方错误；404 空响应报告状态、空响应及路径检查提示。成功状态下的空响应单独报告格式错误。
- 4 项隔离 CLI 回归测试和 4 项已有模型适配器测试通过。覆盖根地址、路径前缀及尾斜杠、配置优先级、环境文件加载、凭据脱敏、空响应与离线回放。测试在临时目录使用合成 `.env`；开发者的 `.env` 保持私有且未被读取。
